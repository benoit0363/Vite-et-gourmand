# Vite & Gourmand — Traiteur Événementiel

Application web dynamique développée dans le cadre du Titre Professionnel de **Développeur Web et Web Mobile** (Niveau 5). 
L'application permet de gérer un catalogue de menus de traiteur, un parcours de commande sécurisé avec calcul de frais de livraison, un espace client (historique, suivi, avis) et un panneau d'administration complet.

---

## 🛠️ Stack Technique

* **Front-end :** HTML5, Tailwind CSS, JavaScript (ES6+), Fetch API
* **Back-end :** PHP 8.x (Architecture orientée objet / style MVC)
* **Base de données :** MySQL 8.0 (avec PDO) et MongoDB (pour la partie analytique/reporting)
* **Outils :** Git, GitHub, Docker & Docker Compose

---

## ⚙️ Installation et Lancement avec Docker (Recommandé)

Ce projet est entièrement conteneurisé à l'aide de **Docker** pour garantir un environnement de déploiement reproductible et isolé.

### Prérequis
* [Docker](https://www.docker.com/) installé sur votre machine.
* [Docker Compose](https://docs.docker.com/compose/) installé.
